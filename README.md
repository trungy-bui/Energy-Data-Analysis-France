# Energy Exploratory Data Analysis

# Overview
This project analyzes real-time electricity usage data in Germany and compares to other european nations (France, Poland, and Denmark) in terms of CO2 Intensity, Fossil-Only Carbon Intensity, and Total Load.

# Executive Summary

### Overview of Findings

# Business and Stackholders' questions
This anaylsis was conducted to address the following questions:
* What is the current carbon intensity (gCO₂/kWh)?
* How does carbon intensity change hour by hour?
* Are there unexpected emission spikes?
* How does Germany compare to France / Poland / Denmark?
* Which country has the lowest average CO₂ intensity?
* Which country is most dependent on fossil fuels?

# Dataset

# Tech Stack
- Python (Pandas, ScikitLearn, Prophet) - Data Extraction and Transformation
- PostgreSQL - Data filtering and aggregation
- Power BI - Visualization and insights
- Git - Version Control

# Data Pipeline

### 2. Data Ingestion
* Loaded raw data directly into PostgreSQL Database
### 3. Data Cleanin & Exploration
* Handled missing and duplicated values
* Transformed data types for further analysis
### 4. Analysis & EDA
* Aggregated metrics using SQL & Pandas
### 5. Visualization
* Published Power BI Dashboard to better communicate the findings
